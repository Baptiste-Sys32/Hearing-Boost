# Hearing Boost

Hearing Boost is a cross-platform desktop utility built with Python and PySide6 (Qt) designed to provide real-time hearing balance adjustments, output device selection, and system-level amplification of up to 500%. It works natively on Linux (via `pactl` for PulseAudio/PipeWire) and Windows (via `pycaw` and Equalizer APO).
